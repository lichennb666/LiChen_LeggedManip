## 1. 最快路径：一键脚本

仓库自带主机检测 + 安装脚本：

```bash
git clone https://github.com/lichennb666/LiChen_LeggedManip.git ~/LeggedManip_Lab
cd ~/LeggedManip_Lab

# 1) 只检测主机环境并给出报告（默认）
./scripts/install_leggedmanip_host.sh check

# 2) 检测通过后：安装 + 验证（一键）
./scripts/install_leggedmanip_host.sh all
```

脚本会自动做：conda 环境 → Isaac Sim 5.1 → Isaac Lab(main) → rsl-rl-lib → 本仓库 → 验证。

可覆盖的环境变量：

| 变量 | 默认 |
|---|---|
| `LEGGEDMANIP_ENV` | `leggedmanip` |
| `ISAACLAB_DIR` | `~/Project/IsaacLab` |
| `LEGGEDMANIP_DIR` | 脚本上一级 |
| `CONDA_SH` | `~/miniconda3/etc/profile.d/conda.sh` |
| `ISAACSIM_VERSION` | `5.1.0` |
| `RSL_RL_VERSION` | `5.0.1` |

> 一键脚本失败时，按下面第 2 节手动分步排查。

## 2. 手动分步（与一键脚本等价）

### 2.1 系统级依赖

```bash
sudo apt update
sudo apt install -y \
  build-essential cmake ninja-build git wget curl \
  libgl1 libglib2.0-0 libsm6 libxext6 libxrender1 libxtst6 libxi6 \
  libgomp1 libvulkan1 libegl1
```

> 缺哪个补哪个；Isaac Sim 无头模式最常缺 `libgl1 / libglib2.0-0 / libvulkan1`。

### 2.2 Miniconda + conda 环境

```bash
# 若无 conda：
#   wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O /tmp/mc.sh
#   bash /tmp/mc.sh -b -p ~/miniconda3

source ~/miniconda3/etc/profile.d/conda.sh
conda create -n leggedmanip python=3.11 -y
conda activate leggedmanip
python -m pip install --upgrade pip
```

### 2.3 Isaac Sim 5.1 + PyTorch

```bash
pip install 'isaacsim[all,extscache]==5.1.0'
pip install torch==2.7.0 torchvision==0.22.0 --index-url https://download.pytorch.org/whl/cu128
```

> 首次运行需接受 EULA：`export ACCEPT_EULA=Y`。

### 2.4 Isaac Lab（**必须 pin 到本机验证过的 commit**）

```bash
git clone https://github.com/isaac-sim/IsaacLab.git ~/Project/IsaacLab
cd ~/Project/IsaacLab
git checkout b4c321024792976150ca55fddb26fa34480d974e   # 本机实测 commit
pip install -e source/isaaclab \
            -e source/isaaclab_assets \
            -e source/isaaclab_mimic \
            -e source/isaaclab_rl \
            -e source/isaaclab_tasks
```

> ⚠️ **不要用 `v2.3.2` tag**——它 pin `rsl-rl-lib==3.1.2`，与本仓库 agent 配置不兼容。
> 想用最新 `main` 也可以，但需自行承担 API 漂移风险；最稳是上面的 commit。

### 2.5 rsl-rl + 本仓库 + 版本对齐 pin

```bash
pip install 'rsl-rl-lib==5.0.1' 'onnxscript>=0.5'

pip install -e ~/LeggedManip_Lab/source/LeggedManip_Lab
pip install -r ~/LeggedManip_Lab/requirements.txt

# 对齐 isaacsim-kernel 的严格 pin（否则运行时报版本不符）
pip install 'numpy==1.26.0' 'psutil==5.9.8' 'typing_extensions==4.12.2'
```

### 2.6 conda 激活钩子（代理豁免，见第 4 节）

本机在 `~/miniconda3/envs/leggedmanip/etc/conda/activate.d/00_isaac_unset_proxy.sh` 里加了
"激活 `leggedmanip` 时对 Isaac 域名追加 `no_proxy`" 的脚本。新机器若也配了代理，需照样加一份。

## 4. 网络 / 代理（重要坑）

Isaac Sim 默认场景资产从 NVIDIA S3 下载。**坏代理**会报：

```
Unable to open the usd file at path:
https://omniverse-content-production.s3-us-west-2.amazonaws.com/.../default_environment.usd
```

处理（二选一）：

```bash
# 方式 1：跑 Isaac 前临时清掉代理
unset HTTP_PROXY HTTPS_PROXY ALL_PROXY http_proxy https_proxy all_proxy

# 方式 2：只让 Isaac 域名绕过代理（其它下载仍走代理）
export no_proxy="omniverse-content-production.s3-us-west-2.amazonaws.com,$no_proxy"
```

## 6. 验证清单（配完必跑）

```bash
conda activate leggedmanip
export ACCEPT_EULA=Y TERM=xterm

# 1) 版本核对
python -c "import isaaclab, isaaclab_tasks, rsl_rl; print('imports OK')"
python -m pip show rsl-rl-lib | grep Version    # 5.0.1
python -m pip show isaacsim   | grep Version    # 5.1.0
python -m pip show torch      | grep Version    # 2.7.0+cu128

# 2) 冒烟训练（4 env，1 迭代）
cd ~/LeggedManip_Lab
python scripts/rsl_rl/train.py --task GO2-PIPER-VBC-Teacher-Shape \
  --num_envs 4 --headless --max_iterations 1
# 出现 "Learning iteration 0/1 ... Training time" 即成功
```

要跑 VBC 训练，还需要一个冻结的 WBC 策略（`LEGGEDMANIP_WBC_POLICY` 指向 `<wbc-run>/exported/policy.pt`）。
本仓库已带 WBC 的 run 产物；没有的话先按第 7 节训练一个 WBC。

## 7. 常用训练/部署命令

```bash
# WBC（底层全身控制器）
TASK=GO2-PIPER-WBC NUM_ENVS=4096 MAX_ITERS=8000 ~/LeggedManip_Lab/scripts/run_train_watchdog.sh

# VBC teacher（高层，需冻结 WBC；阶段一冻底盘）
LEGGEDMANIP_WBC_POLICY=<wbc>/exported/policy.pt VBC_VELOCITY_SCALE=0,0,0 \
TASK=GO2-PIPER-VBC-Teacher-Shape NUM_ENVS=4096 MAX_ITERS=10000 \
  ~/LeggedManip_Lab/scripts/run_train_watchdog.sh

# play
LEGGEDMANIP_WBC_POLICY=<wbc>/exported/policy.pt \
python scripts/rsl_rl/play.py --task GO2-PIPER-VBC-Teacher-Shape \
  --checkpoint logs/rsl_rl/go2_piper_vbc_shape_teacher/<run>/model_<N>.pt --num_envs 1
```

环境变量：`LEGGEDMANIP_WBC_POLICY`、`VBC_VELOCITY_SCALE`（`0,0,0` 冻结 / `0.4,0.3,0.5` 解冻）、
`LEGGEDMANIP_ENV`、`CONDA_SH`。

## 8. 已知坑（务必先看）

1. **驱动版本**：Isaac Sim 5.1 要 **580.x**，595 不兼容。
2. **numpy 必须 <2**（`1.26.0`），否则报错。
3. **IsaacLab 别用 `v2.3.2` tag**（pin 老 rsl-rl）。
4. **代理**：坏代理会劫持 Isaac 资产下载（见第 4 节）。
5. **显存**：一个 4096 训练约 7~12GB；24GB 卡最多并发 2 个，第三个会 OOM 或拖慢数倍。
6. **play / VBC 训练必须带 `LEGGEDMANIP_WBC_POLICY`**。
7. **停止训练要连看门狗一起停**（否则自动重启），安全写法见下方。
8. **`save_interval`**：WBC/VBC 建议 250（默认 1000，中断会丢最近的改进）。
9. 训练配置 dump 在 `<run>/params/env.yaml`，是确认改动是否生效的**权威依据**。

停止训练（安全写法，避免误杀自身 shell）：

```bash
for p in $(pgrep -x python); do
  c=$(tr '\0' ' ' < /proc/$p/cmdline); case "$c" in *"scripts/rsl_rl/train.py"*) kill -9 "$p";; esac
done
for p in $(pgrep -f run_train_watchdog.sh); do
  a2=$(tr '\0' '\n' < /proc/$p/cmdline | sed -n 2p); [ "$a2" = "-c" ] && continue
  kill -9 "$p"
done
```
